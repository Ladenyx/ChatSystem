Khung JavaFX 1.2 tham chiếu token và cấu trúc điều hướng từ các node trên, dùng Primer Light/Dark + Ikonli theo tech stack. Các màn hình hiện là khung để gắn FXML, chưa phải bản triển khai đầy đủ của các frame Figma. Khi làm giai đoạn 3–4, bổ sung link node cụ thể cho từng màn hình và đối chiếu với ảnh chạy thực tế.

Xem [khung desktop](desktop-ui.md) để biết cách thêm route, controller và theme.
