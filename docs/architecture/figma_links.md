# Wireframe và tài liệu tham khảo Figma — ChatSystem

[File Figma của nhóm](https://www.figma.com/design/4kSG28zCQIaiT5JpAoxAKb/Chat-System).

Theo cập nhật của nhóm ngày 15/11/2026, file hiện gồm wireframe và các thành phần/tài liệu tham khảo, chưa phải bộ giao diện cuối cùng đã chốt:

| Phân hệ | Trạng thái wireframe |
| --- | --- |
| Admin App | Đã hoàn thành wireframe |
| User Client | Đang thực hiện, chưa hoàn thành wireframe |

Khi triển khai Admin, dùng wireframe đã hoàn thành để bám bố cục và luồng thao tác. Với User, các phần wireframe hiện có chỉ phản ánh tiến độ hiện tại và có thể thay đổi khi nhóm hoàn thiện. Màu, font và token trong file là tham khảo cho khung UI, chưa được coi là thiết kế trực quan cuối cùng.

| Phần tham chiếu cho khung UI 1.2 | Node |
| --- | --- |
| Bộ nền tảng: màu, Inter, spacing, radius | [Foundations — 19:71](https://www.figma.com/design/4kSG28zCQIaiT5JpAoxAKb/Chat-System?node-id=19-71) |
| Rail User Client | [WF / Rail — 35:2](https://www.figma.com/design/4kSG28zCQIaiT5JpAoxAKb/Chat-System?node-id=35-2) |
| Sidebar phân nhóm Admin App | [Sidebar — 192:1076](https://www.figma.com/design/4kSG28zCQIaiT5JpAoxAKb/Chat-System?node-id=192-1076) |

Khung JavaFX 1.2 tham khảo các node đang có ở trên, dùng Primer Light/Dark + Ikonli theo tech stack. Các màn hình hiện là khung để gắn FXML; phần User chưa thể coi là triển khai theo wireframe hoàn chỉnh. Khi làm giai đoạn 3–4, bổ sung link node cụ thể cho từng màn hình và đối chiếu với ảnh chạy thực tế theo tiến độ wireframe của từng phân hệ.

Xem [khung desktop](desktop-ui.md) để biết cách thêm route, controller và theme.
