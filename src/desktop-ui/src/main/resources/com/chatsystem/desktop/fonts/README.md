# Inter

Inter 4.1 by Rasmus Andersson, downloaded from the [official release](https://github.com/rsms/inter/releases/tag/v4.1). The bundled static TTF files are unmodified and include Vietnamese glyphs. `LICENSE.txt` contains the SIL Open Font License 1.1.

The application loads Regular (400), SemiBold (600), and Bold (700) locally; no font download is needed at runtime. This matches the Inter family used in ChatSystem's Figma foundations.
